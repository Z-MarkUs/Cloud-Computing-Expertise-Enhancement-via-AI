# Cloud Computing Expertise Enhancement via AI
• Implemented a RAG framework to enhance chatbot responses by integrating generative language models with
curated cloud computing knowledge.

• Developed a semantic retrieval pipeline using Microsoft Azure services, including Blob Storage and Cognitive
Search, for real-time access to domain-specific knowledge.

• Deployed using Docker containers, ensuring scalability & reliability in handling knowledge-intensive queries.

• Designed a Flask-based API for seamless interaction between the backend retrieval system and user interface.
